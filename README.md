### Тестовое задание для прохождения стажировки [Авито](https://github.com/avito-tech/tech-internship/tree/main/Tech%20Internships/Frontend/Frontend-trainee-assignment-spring-2025)
Проект написан на React 19 с ипользованием react-router-dom на языке TypeScript.

### Основная информация 
Для запуска необходимо установить [тестовый сервер](https://github.com/avito-tech/tech-internship/tree/main/Tech%20Internships/Frontend/Frontend-trainee-assignment-spring-2025/server) и запустить его локально на порте `http://localhost:8080/`. После чего запустить [данный проект](https://github.com/Hprimer/avito-hprimer) тоже локально на порте `http://localhost:3000/`

### [Инструкция по запуску back-end](https://github.com/avito-tech/tech-internship/tree/main/Tech%20Internships/Frontend/Frontend-trainee-assignment-spring-2025/server#readme)

### Запуск front-end
**установить зависимости:**
```bash
npm install
```
**локальный запуск на порту 3000:**
```bash
npm start
```
